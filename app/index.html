ℹ️ How this works

BP and Comp auto-fill from the Powers PDF (⬆ Import Powers PDF) in home-team perspective. ⬇ Load model predictions pulls every computer system you've toggled on in the ⚙ Prediction systems panel from thepredictiontracker.com. The Vegas ● column is always the live market line. In a pool, the number on each team's pick button is the pool's locked spread instead — the actual number your pick is graded against — and Model #/Edge are computed against that locked number, not live Vegas. Under the Edge pill, a 🔑 key number tag (minor/moderate/major) scores how close the edge sits to 3, 7, or another number final margins cluster around — full credit for landing right on one, fading credit the further away, none once you're well clear of all of them. CLV shows how far live Vegas has drifted from the locked line — green/positive once you've picked means you beat the market, red/negative means it moved away from your number. A ⚡ next to CLV, with the row tinted amber, flags games where the market's recent move and your model's remaining disagreement with the current line both point the same way. Outside a pool, Model # is a weighted average of every filled number you've enabled — BP, Comp, and each toggled system default to equal weight; live Vegas defaults to weight 0, so it's shown for reference but excluded from Model # unless you give it a positive weight yourself.

How to use Edge board

Quick start

  1. Go to Settings (the ⚙ gear icon, top right), paste your free API key from the-odds-api.com, click Save key.
  2. Click ↻ Refresh lines (top right). The board fills with this week's NCAAF games and live spreads.
  3. The numbers in Model # are: BP and Comp (auto-filled from the Powers PDF), any prediction systems you've toggled on in the Prediction Systems panel on the Edge Board tab (auto-filled from thepredictiontracker.com via ⬇ Load model predictions), and — if you give it a weight — the live Vegas line (Vegas defaults to weight 0, so it's excluded from Model # by default; it's still always shown as the market reference). Model # is a weighted average of whichever are filled and enabled.
  4. If you're in more than one pool, My Picks → ⊞ Compare picks across pools lines up every game with a pick, across Overall and every pool, so you can see at a glance where two entries picked the same side (highlighted) or split.
  5. Click ⬆ Import Powers PDF and pick that week's Powers newsletter — BP and Comp fill in automatically for every game it matches.
  6. Click ⇅ Re-sort by edge to push the biggest edges to the top.
  7. In My picks, add a pool entry. Back on the board, pick the entry from Picking for, then star your favorite games (max 7) for that entry.
  8. Repeat the star step per entry. Review them all under My picks.

What each column means

  • Game — away @ home, with kickoff time.
  • BP — Brad Powers' line, auto-filled from the Powers PDF (page 2), converted to home-team perspective.
  • Comp — the computer projected line, auto-filled from the Powers PDF (page 6), home perspective.
  • Prediction systems — any computer systems you've enabled in the ⚙ Prediction systems panel on the board, pulled from thepredictiontracker.com. Each toggled system adds one number to the average.
  • Vegas ● — always the live home-team spread (book shown beneath). Outside a pool it defaults to weight 0, so it's shown for reference but excluded from Model # unless you give it a weight yourself in the ⚙ Prediction systems panel; BP/Comp/your toggled systems default to equal weight and ARE included. In a pool it's for reference only — see CLV below.
  • Model # — outside a pool, a weighted average of every filled, enabled number (BP, Comp, and each toggled system default to equal weight; live Vegas defaults to weight 0 and is excluded unless you give it one). In a pool, live Vegas is swapped for the pool's locked spread (shown on each team's pick button), since that's the number your pick is actually graded against.
  • CLV — pool only. How far live Vegas has drifted from the locked line since it locked. See the CLV FAQ below for the full explanation.
  • Edge — pick — the side to take, the market number for that side, and the points of value in the pill. In a pool this is edge vs. the locked line, not live Vegas.

Which number is on the team pick buttons?

Outside a pool, the live Vegas line. In a pool, the locked spread — the number your pick is actually graded on — falling back to a provisional live number only before that pool's line has locked.

How the edge is read

  • Edge = the gap between Model # and the live line. It also tells you which side that gap favors and the number you'd actually bet.
  • Green = the gap clears your threshold (set in Settings, default 1.5). Deep green = a strong edge (default ≥ 3).
  • Red = the gap is below threshold — your number basically agrees with the market, so no real edge.

FAQ

Do I need IT or admin rights?

No. The API key is a free personal signup. Everything runs in your browser and saves locally.

Will it use up my free API calls?

Only when you click Refresh lines. One click = one pull of all games. The remaining count shows top-right after each refresh.

Where do my picks and numbers go?

They're stored in this browser (localStorage). Use Settings → Export to back them up or move browsers.

How does the Powers import work?

It reads page 2 (BP line) and page 6 (Comp line) of the Powers newsletter, converts both to home-team perspective, and matches each game to your board by team name. Games it can't match are counted next to the button and logged to the browser console so you can fill those by hand.

How do the prediction systems work?

In the ⚙ Prediction systems panel on the Edge Board, toggle on any of the ~40 computer systems tracked at thepredictiontracker.com (Sagarin, ESPN FPI, Donchess, Dokter, Big 200, and more). Hit ⬇ Load model predictions on the board and each enabled system's line for that week gets averaged into Model # for every game it covers. Your toggle choices sync across devices.

Why does the same point edge look different on different games?

A 1-point edge doesn't mean the same thing on every spread — a 1-point edge on a 4-point spread matters more than the same 1-point edge on a 20-point spread. Two other approaches were tried and rejected before landing here, worth knowing since both are common instincts: a win-probability model gives the identical number for a 1-point edge regardless of spread size (spreads are built to make that math translation-invariant); percent-of-spread (edge ÷ line) fixes that but blows up near a pick'em game — a 1-point edge on a 1-point spread reads as 100%, and a true pick'em is a divide-by-zero.

The 🔑 key number tag avoids both problems because it isn't a smooth formula. NCAAF final margins cluster heavily at 3 and 7 (field goal, touchdown), with secondary clustering at 10, 14, 6, 4, 17 — each weighted by how much it's commonly cited as mattering (illustrative weights, not fitted to real NCAAF data). Your edge gets full credit for landing right on one of these, and fading partial credit the closer it gets without quite touching — a 2-point edge sitting between 4 and 6 still scores close to a full hit, since it's right in that cluster, while the same 2-point edge out at a 20-point blowout scores nothing. Bucketed into minor / moderate / major; no badge at all when there's genuinely no signal.

What's CLV?

Closing Line Value — only shown in a pool, since it needs a locked line to compare against. It's the difference between the pool's locked spread and the current live Vegas line for that game. Before you pick, it's shown plainly as the raw market movement. Once you've picked a side, it flips to your pick's perspective and colors it: green/positive means the market has moved away from your number since it locked — you beat the closing line, a good sign for your pick. Red/negative means the opposite.

What does the ⚡ next to CLV mean?

It flags a game where two signals agree: the market's move since lock (locked → live), and your model's remaining disagreement with the current market (live → Model #), both point the same direction. Example: a team locked at −6.5, the live line has already drifted to −9, and Model # still says −18.5 — the market's been sliding that team's way, and the model thinks there's more room to go. The row tints amber so these stand out whether or not you've picked them yet. Check ⚡ CLV + Model # aligned in the board toolbar (pool view) to filter the board down to just these games.

Why is a game missing?

The board shows what the books currently list for NCAAF. Games far out, or off the board, may not appear until closer to kickoff.
