ℹ️ How this works

My Numbers is your private personal projected spread for each game; its small My edge label compares that line against the same live/locked reference the board is using, but it does not change PickGauge Model # or the main Edge ranking. BP and Comp auto-fill from the Powers PDF (⬆ Import Powers PDF) in home-team perspective. ⬇ Load model predictions pulls the available computer-system data used by your selected systems and by PickGauge Model #. When PickGauge Model # is active, it appears as one standalone board column; its internal component systems stay behind the scenes unless you separately turn one on as a comparison. The Vegas ● column is always the live market line. In a pool, the number on each team's pick button is the pool's locked spread instead — the actual number your pick is graded against — and Model #/Edge are computed against that locked number, not live Vegas. Under the Edge pill, a 🔑 key number tag (minor/moderate/major) scores how close the edge sits to 3, 7, or another number final margins cluster around — full credit for landing right on one, fading credit the further away, none once you're well clear of all of them. The X/Y agree tag shows how many enabled, positively weighted model inputs favor the recommended side; Vegas itself is excluded from that count. CLV shows how far live Vegas has drifted from the locked line — green/positive once you've picked means you beat the market, red/negative means it moved away from your number. A ⚡ next to CLV, with the row tinted amber, flags games where the market's recent move and your model's remaining disagreement with the current line both point the same way. Outside a pool, Model # is a weighted average of every filled number you've enabled — BP, Comp, and each toggled system default to equal weight; live Vegas defaults to weight 0, so it's shown for reference but excluded from Model # unless you give it a positive weight yourself.

How to use Edge board

Quick start

  1. Click ↻ Refresh lines (top right) — PickGauge's shared odds connection works automatically once you're signed in, no key or setup needed. The board fills with this week's NCAAF games and live spreads. (Want your own separate refresh budget instead of the shared one? Add a personal key in Settings — entirely optional.)
  2. PickGauge Model # is a standalone proprietary blend of five selected prediction models plus some influence from the current Vegas line. When it is off, the customizable Model # uses BP, Comp, any individual prediction systems you've toggled on, and — if you give it a weight — the live Vegas line (Vegas defaults to weight 0).
  3. If you're in more than one pool, My Picks → ⊞ Compare picks across pools lines up every game with a pick, across Overall and every pool, so you can see at a glance where two entries picked the same side (highlighted) or split.
  4. Click ⬆ Import Powers PDF and pick that week's Powers newsletter — BP and Comp fill in automatically for every game it matches.
  5. Use ⇅ Sort & filter to order the Edge Board by Edge, Cover %, Game time, Rotation #, or another model/market column. Games without a kickoff or rotation number sort to the bottom.
  6. Use Export board ▾ for an offline copy. Weekly Board PDF always prints the full slate regardless of temporary filters; Current view PDF prints only the games showing now; Board CSV keeps one raw column per enabled model input for Excel/Sheets.
  7. In My picks, add a pool entry. Use the Viewing bar at the top to select that pool and entry, then choose a team from Snapshot or Pick Board → This Week — up to the pool's pick limit (7 by default) for that entry.
  8. Repeat per entry. Review every entry's picks under My picks.

What each column means

  • Game — away @ home, with kickoff time.
  • BP — Brad Powers' line, auto-filled from the Powers PDF (page 2), converted to home-team perspective.
  • Comp — the computer projected line, auto-filled from the Powers PDF (page 6), home perspective.
  • Prediction systems — any computer systems you've enabled in the ⚙ Prediction systems panel on the board. Each toggled system adds one number to the average.
  • Vegas ● — always the live home-team spread (book shown beneath). Outside a pool it defaults to weight 0, so it's shown for reference but excluded from Model # unless you give it a weight yourself in the ⚙ Prediction systems panel; BP/Comp/your toggled systems default to equal weight and ARE included. In a pool it's for reference only — see CLV below.
  • Model # — outside a pool, a weighted average of every filled, enabled number (BP, Comp, and each toggled system default to equal weight; live Vegas defaults to weight 0 and is excluded unless you give it one). In a pool, live Vegas is swapped for the pool's locked spread (shown on each team's pick button), since that's the number your pick is actually graded against.
  • CLV — pool only. How far live Vegas has drifted from the locked line since it locked. See the CLV FAQ below for the full explanation.
  • Edge — lean — which side the model leans toward, the market number for that side, and the points of value in the pill. A Strong/Good/Slim tag above the team name rates how much value is actually there: Slim means the model and the market barely disagree, so it's a lean worth noting rather than a recommendation. In a pool this is edge vs. the locked line, not live Vegas.

Which number is on the team pick buttons?

Outside a pool, the live Vegas line. In a pool, the locked spread — the number your pick is actually graded on — falling back to a provisional live number only before that pool's line has locked.

How the edge is read

  • Edge = the gap between Model # and the live line. It also tells you which side that gap favors and the number you'd actually bet.
  • Green = the gap clears your threshold (set in Settings, default 1.5). Deep green = a strong edge (default ≥ 3).
  • Red = the gap is below threshold — your number basically agrees with the market, so no real edge.

FAQ

Do I need IT or admin rights?

No. Sign in and PickGauge can use the shared server-side odds connection automatically. A personal Odds API key is optional and stays on this device if you choose to add one.

Will it use up my free API calls?

Not necessarily. PickGauge checks the shared cache first and reuses recent odds instead of spending another upstream call when the shared data is still fresh. If a new fetch is needed, it pulls the current NCAAF slate in one request. Shared-provider quota details are operational information and do not affect how you use the board.

Where do my picks and numbers go?

They're saved locally in this browser and, when you're signed in, your private PickGauge state syncs to your account so it can follow you across devices. A personal Odds API key is device-local and is never included in that sync. Settings → Export gives you a separate backup copy.

How does the Powers import work?

It reads page 2 (BP line) and page 6 (Comp line) of the Powers newsletter, converts both to home-team perspective, and matches each game to your board by team name. Games it can't match are counted next to the button and logged to the browser console so you can fill those by hand.

How do the prediction systems work?

In the ⚙ Prediction systems panel on the Edge Board, you can either enable PickGauge Model # as one standalone model or toggle any of a curated set of 17 individual computer systems for a custom Model #. A real imported sheet (or CSV) can still supply any of the ~48 systems PickGauge recognizes — an already-enabled system always keeps working and counting toward Model # — but the checklist itself only ever offers this curated 17 to turn on. PickGauge's internal component systems do not automatically appear as board columns; individual systems only appear when you turn them on separately. Your choices sync across devices.

Why does the same point edge look different on different games?

A 1-point edge doesn't mean the same thing on every spread — a 1-point edge on a 4-point spread matters more than the same 1-point edge on a 20-point spread. Two other approaches were tried and rejected before landing here, worth knowing since both are common instincts: a win-probability model gives the identical number for a 1-point edge regardless of spread size (spreads are built to make that math translation-invariant); percent-of-spread (edge ÷ line) fixes that but blows up near a pick'em game — a 1-point edge on a 1-point spread reads as 100%, and a true pick'em is a divide-by-zero.

The 🔑 key number tag avoids both problems because it isn't a smooth formula. Its weights are fitted to 5,705 FBS-vs-FBS regular-season games from 2018–2025: final margins cluster most heavily at 3 and 7, with additional signal at 10, 14, 21, 17, and 4. Your edge gets full credit when the range between the market and Model # crosses one of those numbers, and fading partial credit when it gets close without quite reaching it. The resulting score is bucketed into minor / moderate / major; no badge is shown when there is genuinely no key-number signal.

What's CLV?

Closing Line Value — only shown in a pool, since it needs a locked line to compare against. It's the difference between the pool's locked spread and the current live Vegas line for that game. Before you pick, it's shown plainly as the raw market movement. Once you've picked a side, it flips to your pick's perspective and colors it: green/positive means the market has moved away from your number since it locked — you beat the closing line, a good sign for your pick. Red/negative means the opposite.

What does the ⚡ next to CLV mean?

It flags a game where two signals agree: the market's move since lock (locked → live), and your model's remaining disagreement with the current market (live → Model #), both point the same direction. Example: a team locked at −6.5, the live line has already drifted to −9, and Model # still says −18.5 — the market's been sliding that team's way, and the model thinks there's more room to go. The row tints amber so these stand out whether or not you've picked them yet. Check ⚡ CLV + Model # aligned in the board toolbar (pool view) to filter the board down to just these games.

Why is a game missing?

The board shows what the books currently list for NCAAF. Games far out, or off the board, may not appear until closer to kickoff.
