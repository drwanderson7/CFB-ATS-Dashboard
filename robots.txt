# PickGauge — robots.txt
#
# The marketing/info pages (/, /methodology, /contact, /privacy, /terms,
# /responsible-play) are meant to be publicly indexed. Everything below is
# deliberately excluded:
#
#   /app/  — the signed-in application itself. There's no content here for
#            a crawler to usefully index (it's a client-rendered SPA behind
#            Clerk auth), and a search result linking straight into the app
#            shell rather than the marketing site is a worse landing
#            experience for everyone. This is the "noindex /app/" P1 item
#            from the launch audit.
#   /api/  — serverless JSON endpoints, not pages. Nothing here should ever
#            be crawled or indexed.
#   /pricing.html — already carries its own <meta name="robots"
#            content="noindex, nofollow"> tag (Aug 25 session) since it's
#            not linked from anywhere public yet; listed here too as
#            defense-in-depth, same reasoning as that page's own comment.
#
# No sitemap.xml exists yet in this project.

User-agent: *
Disallow: /app/
Disallow: /api/
Disallow: /pricing.html
